Redis Side Project 個人小專題 ~
🔸 選題
自選適宜的專案主題，需應用到 Redis 資料庫的專長與特性，並採用 Redis Commands、及任何程式語言(如：Python, Node.js)，來開發應用程式或系統。
如（不限於此）：
IoT Sensor Dashboard 物聯網感測器儀表板
Real-time Chat System 即時聊天室
Real-time Leaderboard 極速排行榜系統 (可應用在 On-Line Game Server)
Queue Ticket System 叫號系統（可應用在 銀行、郵局、電信服務門市 等）
Flash Sale System 限時、限量、拍賣叫價搶購系統
Election Counting & Reporting Center 選舉計票與開票中心系統


🔸 應用程式/系統 開發
Redis 進階功能
最低要求為 ~ 至少使用到 2 項 Redis 的進階功能，如： Index, Queue/Stack, Pub/Sub, Aggregation Queries, Pipelines, Transactions, Streams, … 等。
操作介面
最低要求為 ~ 在「cmd 命令提示字元」視窗中，採文字模式來與使用者進行互動。
或使用程式語言本身提供的 GUI 功能來繪製操作介面，並處理與使用者之間的進行互動。
可選擇使用 Browser 做為操作介面，並開發對應的前端及後端應用程式。（必要時也可在前端直接以 WebSocket 連接後端各式伺服器。）
亦可搭配使用全端應用程式框架，如：
Python + Flask
Python + Streamlit / NiceGUI / HTMX ~ 免寫傳統 JS 前端
Python + FastAPI + React / Vue.js ~ 前、後端分離
Node.js + Express + WebSocket
也可以選擇使用其他 Low-Code 的全端開發工具，如：
Node-RED
當然，也可依不同角色的使者，混用以上不同的操作介面。
