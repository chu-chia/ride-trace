# 騎跡交件短片：3 分鐘錄製版

錄製畫面用目前可運作的本機網站。先錄到影片即可；若時間不夠，旁白可邊操作邊說，不必剪輯。錄前關閉個人足跡與帳密畫面，避免洩露私人資料。

|---|---|---|
| 0:00–0:20 | 登入頁 → 首頁 | 「這是騎跡 RideTrace，一個以 Redis 開發的機車車隊即時定位與回放系統。團騎時可以看到隊友位置，並及早發現落隊或失聯。」 |
| 0:20–0:50 | 開啟展示行程，顯示地圖、隊員與路線 | 「行程建立後，可以用邀請碼或 QR code 邀請隊友。手機或 Traccar 回報的位置會進入 FastAPI，再用 Redis GEO 保存即時位置；GEOSEARCH 可查隊友間的距離。」 |
| 0:50–1:20 | 顯示移動中的隊員、事件或警示 | 「每筆回報透過 Pipeline 批次寫入，Pub/Sub 將更新推到網頁；Streams 交給背景 Worker 處理統計和落隊、失聯等警示。Consumer Group 讓多個 Worker 分工，處理完成才 XACK。」 |

| 2:40–3:00 | 簡報的架構頁或首頁 | 「這個專題完成了位置回報、即時顯示、警示、路線與回放。Redis 的地理查詢、即時訊息與事件流，讓這些功能能在同一個系統中運作。」 |

## 錄完立刻做

1. 輸出 MP4，檔名可用 `騎跡_Redis專題展示.mp4`。
2. 上傳 Google Drive，設為「知道連結的人皆可檢視」。
3. 用無痕視窗打開連結，確認影片能播放；再將連結填入繳交 Email。

若沒有可用的即時行程，直接展示已結束行程的回放，旁白保留 Redis 流程即可；不要為了錄影臨時公開個人位置。
