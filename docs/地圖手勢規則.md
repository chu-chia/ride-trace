# 地圖手勢規則（草案，待使用者逐條核對）

> 狀態：**草案**。「建議」欄還沒實作，使用者改完、確認後再一次實作。
> 適用頁面：行程頁 `/trip`、回放 `/replay`、戰情室 `/war`（規劃 `/plan`、足跡 `/footprint` 沒有跟隨，照地圖預設操作）。

## 名詞

- **跟隨某人**：點騎士標記、點隊員表、或按「跟我」。鏡頭每一格把那個人放在畫面中間。
- **全隊**：按「全隊」。鏡頭自動框住所有在線騎士。
- **自由**：沒有跟隨，鏡頭完全由使用者操作。

## 目前三頁不一致的地方（2026-11-18）

| 頁面 | 使用者動了地圖之後 |
|---|---|
| 行程頁 | 暫停跟隨 12 秒，之後自動恢復原本的跟隨對象 |
| 回放 | 拖曳或滾輪直接把跟隨關掉（`setFollow('off')`），要自己再按 |
| 戰情室 | 暫停（`autoFollow = false`），要按「全隊」才恢復 |

已修好的前提（890e536）：手指／滑鼠按在地圖上時，跟隨不再每格 `jumpTo`（以前 `jumpTo` 會中止 MapLibre 正在辨識的手勢，跟隨中拖不動地圖）。

## 實作備註（給之後的人）

- 「繼續跟隨、只改縮放／方向／傾斜」：跟隨時 `M.follow()` 每格只帶 `center`，縮放、方向、傾斜沿用使用者手勢後的值；雙指縮放要以那個人為中心（MapLibre 的 `touchZoomRotate` 以兩指中點為中心，跟隨時要改成 `around: 中心` 或縮放後立即回正）。
- 手勢種類要分清楚：`dragstart` 才算「拖曳」；`zoomstart`／`rotatestart`／`pitchstart` 不應再觸發停止跟隨（目前三頁都把四種事件一起當「動了地圖」）。
- 全隊模式下使用者縮放後，`followGroup` 不能再改 zoom。
