## 已完成的功能

| 頁面 | 重點 |
|---|---|
| `/login` | 帳號＋密碼（scrypt），session 存 Redis（TTL 30 天）。**不接 Google 登入**（使用者決定） |
| `/` | 開團、邀請碼加入、行程列表（已結束→回放）、足跡入口 |
| `/trip?id=` | 即時地圖（WebSocket＋Pub/Sub）、隊友狀態、事件、邀請 QR、網頁定位回報、Traccar 設定、建立者開始／移出、結束自己的紀錄 |
| `/replay?id=` | 全隊同步回放、時間軸＋倍速 1～300×、事件跳轉、跟拍鏡頭（3D、車頭朝上）、依隊員／速度／海拔上色、海拔與速度曲線、整趟摘要 |
| `/footprint` | 全年迷霧地圖：日期範圍、月份、一天中的時段（清晨／白天／傍晚／夜間）、每月小月曆、逐月播放 |

位置來源：網頁 `POST /api/track`；Traccar Client `GET/POST /osmand`（舊版 OsmAnd query 與新版 JSON 都支援，裝置 ID 由 `/api/me/device` 產生）。

## 重要設計決定（不要改回去）

1. **底圖**：OpenFreeMap（深色 dark／淺色 liberty）＋國土測繪中心衛星；3D＝AWS terrarium 地形＋自建 `fill-extrusion` 建築＋`setSky`。使用者不喜歡 CARTO，指定「深色能看到 3D 房子跟山」。
2. **MapLibre 5 的坑**（都已處理，改 `mapbase.js` 時注意）：
   - 鏡頭動畫被打斷後 `_elevationFreeze` 會卡住，中心高度停在 0 → 鏡頭鑽進武嶺的山裡。`fixElevation()` 在 moveend/idle 校正。
   - 跟隨模式用 `M.follow(center)`：關掉 `centerClampedToGround`，高度取周圍 9 點平均再低通濾波，避免上下抖動；使用者拖曳時 `M.unfollow()`。
   - `isStyleLoaded()` 在圖磚載入中都是 false，不能拿來判斷；用 `onStyle()` 的 hook 或自己的 `styleReady` 旗標。
   - `onStyle()` 若在 style.load 之後才登記，會立刻執行一次（回放頁是先 await 資料才登記）。
3. **前端標記平滑移動**：收到新位置不直接跳，在「距上一筆的時間」內線性滑過去（`trip.js` 的 `moveTo`＋`tick`）。軌跡線尾巴接標記目前位置。
4. **模擬器時間戳用重播時間**（1 倍速），不是真實時鐘；人物相關事件（lost/back/stop/end）用該人裝置回報的 `ts`。所以 30 倍速跑完的行程，回放仍是真實時長。真實手機補傳也因此正確。
5. **Streams ID**：行程軌跡 `track:` 用 `*`（ts 存欄位，回放時依 ts 排序）；足跡 `footprint:` 用 `{ts}-*`，才能 `XRANGE` 依時間查。
6. **地圖比對**：本機 Valhalla `trace_attributes`，costing 用 `auto`（用 motorcycle 時國道 6 號對不上，會變直線）。只套用在展示軌跡（`tools/match_tracks.py`），真人即時回報還沒做比對。
7. **迷霧**：格子 0.0015°（約 160 m），兩點間每 80 m 補格子；`fog:{uid}:{YYYYMMDD}:{時段}` Set，查詢時 `SUNION`。前端自己算 Web Mercator 畫在 canvas（地圖不旋轉不傾斜）。

## 驗證方法（之前怎麼測的）

- 後端：`curl` 帶 `authorization: Bearer <token>`（登入 API 回傳 token）。
- 前端：無頭 Chrome＋CDP。開 `--remote-debugging-port=9333 --use-angle=swiftshader`，用 Python websockets 設 cookie `qiji_session`、`Page.navigate`、`Runtime.evaluate`、`Page.captureScreenshot`。頁面有 `window.qijiMap` 可以讀鏡頭狀態。
- 模擬器測完記得 `pkill -9 -f tools.simulate`。曾經因為舊的模擬器沒關，兩個程序用同一個機器人帳號回報，位置來回跳，誤以為是 bug。
- 測試完把測試行程收掉：`HSET trip:{id} status ended`、刪 `trip:{id}:active`、刪指向它的 `user:*:active_trip`，否則使用者真的回報會被送進測試行程。
