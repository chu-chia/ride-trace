## 2. 重點改動（給之後改程式的人）

- **SOS（#1）**：`trip.html` `.sosFab` 的 bottom 上限改成 `100dvh - var(--sat) - 62px`、`z-index:10`。抽屜全開時 SOS 在右上、標題列旁邊（`.rtop` 右邊本來就留了工具列的空間）。
- **導航 SOS 橫幅（#2）**：`nav.js` `showBanner(..., { sosUid })`，橫幅記住 `data-sos-uid`，同一個人的 `sos_off` 可以蓋掉。
- **MapLibre padding 會疊加（#3）**：`easeTo({padding})` 留下的 padding 會被 `fitBounds` 再加一次，加起來超過畫面高度就放棄。`plan.js` `fitNow()` 先 `setPadding(0)`。其他頁如果出現「Map cannot fit」也是這個原因。
- **集合點（#4）**：`trip.js` `meetPoint()`：有 `kind:'meet'` 就用，沒有就用路線起點（`implicit:true`）。
- **GPS 狀態（#5）**：`S.gps.fixed` 第一次 `onFix` 才設，`meSharing()` 看 `fixed`。
- **進度投影（#6）**：`geo.py project_on_route` 沒有 hint 時，在「最近距離＋30 m」內取 index 最小的線段。
- **toast 位置（#7）**：`app.css` 最後幾條：導航時用 `--nv-top`、一次一則；手機行程頁排在 `.rtop` 下面；電腦／橫向在地圖區置中。
- **頂部安全區（#39）**：新增 `--sat`（`app.css` 開頭）＝`env(top) + min(16px, env(top)*100)`，安全區是 0 時不加。全站 39 處 `env(safe-area-inset-top)` 都換成 `var(--sat)`，**之後新寫的頂部位置也請用 `var(--sat)`**。
- **抽屜動畫（#12）**：`common.js` `SHEET_ANIM_MS = 620`（轉場是 `--dur-3` 0.55 s，以前只逐格更新 0.36 s）。`trip.js panelPad()` 用抽屜的目標高度算留白。
- **推播（#16、#19）**：`push.py` 新增 `end`（行程結束，網址 `/replay?id=`），`events.py NOTIFY_TYPES` 加 `end`。`self_payload()`：收件人就是當事人時，body 改成「你＋事件文字」。設定頁的通知清單由後端 RULES 產生，會自動多一個「行程結束」開關。
- **停靠站吸附（#14）**：`routes.py valhalla_routes`：有名字的中間點（不是「地圖上的點」、不是拖曳點）加 `search_filter: {min_road_class: "tertiary"}`；算不出來就退回不限制。實測台北車站→北投溫泉博物館→關渡宮→淡水，2 個迴轉變 0 個、少 1 km；山區測試會正常退回。`radius` 試過沒有效果。
- **離線頁（#23）**：`sw.js` 只攔 navigate，網路優先，失敗才回內嵌的離線頁（不快取任何檔案）。`common.js` 每一頁都會註冊 SW（以前只有開通知才註冊）。
- **網路慢（#24）**：地圖頁 `<html data-theme="dark">`（mapbase 之後照底圖改）；`trip.html` SOS 後面有一段內嵌 script，`trip-extra.js` 接好 SOS 之前按下會顯示「撥打 112」，接好後設 `window.__qijiSosReady`。
- **toast 圖示（#31）**：`common.js TOAST_ICO`：呼叫端照舊傳字（'鈴'、'亮'…），在這裡換成 SVG；沒對應的字照舊顯示。
- **頭像（#29）**：`initialOf()` 取第一個字（英文轉大寫），結尾是數字的維持顯示數字。
