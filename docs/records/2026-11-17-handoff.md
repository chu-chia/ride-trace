## 重要決定（不要改回去）

- **台灣路權**（使用者更正過）：機車國道、快速道路都不行；重機國道不行但**國道3甲例外**、快速道路可以；汽車都可以。Valhalla：`exclude_tolls`（國道在 OSM 都標收費，連 3甲 也是）＋`use_highways`；算完用 `trace_attributes` 檢查，違規回傳 `warnings`。
- **`trace_attributes` 要用和算路線相同的 costing**（不然 edge_walk 會失敗），失敗再分段 map_snap（上限 200 km）。
- **個人速度**：短暫停車算、休息（連續靜止 > 3 分鐘）不算、走了 2 km 以上國道的趟（開車／搭車）整趟排除；類別＝道路等級×市郊×彎路（1.5 km 窗口路徑長／直線 > 1.3）。臺北車站→武嶺依個人速度 5:27，Google 5:30～5:34。
- **測速不再加強**：使用者騎車用神盾，騎跡的測速只當 Redis 展示。
- **規劃頁以網頁內操作為主**，Google 匯入是選用。

## 踩過的坑（新）

- redis-py 8 的 `FT.SEARCH` 回傳 RESP3 dict（`results`／`id`），工具裡要兩種格式都處理。
- `TS.INCRBY` 是「在上一個值上加」→ `ts:sys:writes`、`ts:sys:pubsub` 是**累計計數器**，速率要取 bucket 最大值相減。
- 戰情室曾用 `.dot` 當進度點 class，蓋掉地圖標記的 `.rider .dot`（標記只剩名字）→ 改 `.pdot`。新頁面不要用 `.dot`、`.rider` 這類共用 class 名稱。
- 模擬器的時間戳是虛擬時間，跑完後機器人的 `user:{uid}:last` 會在「未來」，再用現在時間送點會被當成舊資料（footprint 不寫）。測試要用 `last.ts + 60000`。
- 測試腳本讀新行程 ID 要等 `seq:trip` 變了才讀，不然會拿到上一個行程。
- npx 下載套件被權限擋住；要驗證 Mermaid，改用瀏覽器載入 jsdelivr 的 mermaid 渲染。

### 重要決定與設定
- **金鑰都在 `.env`**（不進版控）：`VAPID_*`（tools/gen_vapid 產生）、`TDX_CLIENT_ID／SECRET`（使用者 TDX 會員的預設金鑰）、`CWA_API_KEY`（使用者給的，和 Jarvis 那組不同）。compose 會傳進 api、worker。
- **推播流程**：`events.emit` 遇到 `NOTIFY_TYPES` → `XADD stream:notify` → worker group `push` → `push.RULES` 決定推給誰（others／all／self）→ `SET push:sent:{eid}:{uid} NX` 去重、`push:calm:*` 冷卻 → pywebpush。404／410 自動刪訂閱。
- **iPhone 推播只能在「加入主畫面」的網頁 App 模式**（用 Safari 加；Chrome 加的可能只是捷徑）。使用者的 iPhone 已訂閱成功（`web.push.apple.com`），帳號 1 共 2 台裝置。
- **TDX 每月只有 3 點（4,500 次）**：cache-aside，`cache:tdx:roadev` 120 秒、`lock:tdx:roadev` 防 stampede、暫存 key＋`MULTI RENAME`；沒有進行中的行程、沒人開規劃頁就完全不呼叫。用量在 `tdx:usage`、後台看得到。端點 `/api/basic/v1/Traffic/RoadEvent/LiveEvent/Highway`（TDX 的 Highway＝省道）。
- **TDX 資料的坑**：有的事件經緯度寫反（自動對調）；里程換算失敗的會被放在台1線 0K（臺北車站前 121.515, 25.0469），這種略過。
- **天氣**：位置先用 GEOSHAPE 換成鄉鎮，只向氣象署要整個縣市（F-D0047-001～085，代號表在 `weather.DATASET`，逐一實測過）；`cache:cwa:{縣市}` 30 分鐘。TDX 的「格點預報」是海象，不能用。**容器是 UTC**，時間顯示一律用 `weather.tw()`（固定 +8）。
- **路況、降雨事件 uid 為空**（全隊共用），觸發的人記在 `by` 欄位；文字裡寫「誰前方多遠」。
- **手機網址**：`tailscale serve --bg --https=8443 http://127.0.0.1:8750` → `https://macbook-pro.tail866fc3.ts.net:8443`（tailnet only；443 是 Jarvis 的 8000）。
- **測試事件**都帶 `test=1`，後台「清掉這個行程的測試事件」會 XDEL 並解除測試 SOS 橫幅（`sos_refresh` 訊息）。
