## 重要決定（不要改回去）

- **台灣路權**（使用者更正過）：機車國道、快速道路都不行；重機國道不行但**國道3甲例外**、快速道路可以；汽車都可以。Valhalla：`exclude_tolls`（國道在 OSM 都標收費，連 3甲 也是）＋`use_highways`；算完用 `trace_attributes` 檢查，違規回傳 `warnings`。
- **`trace_attributes` 要用和算路線相同的 costing**（不然 edge_walk 會失敗），失敗再分段 map_snap（上限 200 km）。
- **個人速度**：短暫停車算、休息（連續靜止 > 3 分鐘）不算、走了 2 km 以上國道的趟（開車／搭車）整趟排除；類別＝道路等級×市郊×彎路（1.5 km 窗口路徑長／直線 > 1.3）。臺北車站→武嶺依個人速度 5:27，Google 5:30～5:34。
- **測速不再加強**：使用者騎車用神盾，騎跡的測速只當 Redis 展示。
- **規劃頁以網頁內操作為主**，Google 匯入是選用。
- **協作**：另一個 agent 在 `~/development/qiji-ui`（`feat/畫面設計`）做畫面，已合併到 main；已通知它之後先 `git merge main` 再改。它新增的檔案：`login-stage.js`、`homebg.js`、`footmini.js`、`login-routes.json`（公開道路線形，可進版控）。

## 踩過的坑（新）

- redis-py 8 的 `FT.SEARCH` 回傳 RESP3 dict（`results`／`id`），工具裡要兩種格式都處理。
- `TS.INCRBY` 是「在上一個值上加」→ `ts:sys:writes`、`ts:sys:pubsub` 是**累計計數器**，速率要取 bucket 最大值相減。
- 戰情室曾用 `.dot` 當進度點 class，蓋掉地圖標記的 `.rider .dot`（標記只剩名字）→ 改 `.pdot`。新頁面不要用 `.dot`、`.rider` 這類共用 class 名稱。
- 模擬器的時間戳是虛擬時間，跑完後機器人的 `user:{uid}:last` 會在「未來」，再用現在時間送點會被當成舊資料（footprint 不寫）。測試要用 `last.ts + 60000`。
- 測試腳本讀新行程 ID 要等 `seq:trip` 變了才讀，不然會拿到上一個行程。
- npx 下載套件被權限擋住；要驗證 Mermaid，改用瀏覽器載入 jsdelivr 的 mermaid 渲染。
