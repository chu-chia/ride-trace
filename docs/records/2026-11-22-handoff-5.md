## 2. 地圖按鈕規則（照 Google／Apple 地圖）

| 按鈕 | 第一下 | 第二下 |
|---|---|---|
| 指北針（一般） | 有轉 → 北方朝上（傾斜不動） | 朝北但有傾斜 → 放平；朝北又平 → 指北針收起來（`.idle`） |
| 指北針（導航） | 車頭朝上＋傾斜 ↔ 北方朝上＋俯視 | 按鈕文字顯示目前是「車頭」或「朝北」（`nav.js` `syncNavCompass`） |
| 3D（導航中） | 只換立體建築／地形 | 傾斜交給指北針；導航時 `M.allowTilt(true)`，2D 也能傾斜 |
| 地圖樣式 | 打開選單（目前的打勾） | 再按、點外面、Esc 關掉（`mapbase.js` `styleMenu`） |

- `mapbase.js`：`addCompass` 重寫（`b.sync()`）、`styleMenu()`、`M.styles`、`M.flatten()`、`M.allowTilt()`／`M.tiltOK`；`set3d` 在 tiltOK 時不動 pitch；`applyDim` 用 `is3d || tiltOK` 決定 maxPitch。
- 電腦版戰情室加了 3D 鈕和指北針（`war.html` 桌面 toolbar、`war.js`）。
- 修：規劃頁 `.pl button{font:inherit…}` 洗掉地圖按鈕樣式（改 `.pl button:not(.tool)`）；導航 `body.nav .nv{display:block}` 把橫幅、聚焦列的 flex 蓋掉（補 `body.nav .nv-free,.nv-banner,.nv-focus{display:flex}`）。

## 3. 動畫（Apple 式彈簧）

- `app.css` `:root`：`--ease-spring`（dampingFraction 0.82、response 0.42）、`--ease-bounce`（0.68／0.5）、`--ease-out`、`--dur-1/2/3`（.16／.32／.55s）。曲線是用 iOS spring 公式算出來的 CSS `linear()`，寫在 `:root` 後面的 `@supports` 裡（舊瀏覽器退回 cubic-bezier）。要調彈性就重算這兩條。
- 側欄收合／展開：`common.js` `animatePanel()` 用 clip-path 從現在大小裁到目標大小（不動 width／height）；收合時先加 `.small.closing`，`.closing` 讓版面維持展開到動畫結束，但 `body:has(.panel.small)` 的元件（回放播放列、全隊進度條、跟隨膠囊、轉彎小卡）已經同時開始滑。以前的 `.panel{transition:width .25s}` 已拿掉。只在 >760px 且沒開「減少動態」時跑。
- 分段按鈕（`.seg`）換選項：`common.js` 的 MutationObserver 看到 A 去掉 `on`、B 加上 `on`，就放一塊 `.seg-ghost` 從 A 滑到 B。各頁不用改程式。
- 按下縮小、放開彈回：`app.css` 一個 `:is(.tool,.icon-btn,.btn,.panel-act,…)` 群組。設定頁開關按住拉長。抽屜、toast、樣式選單都換成彈簧曲線。
- `prefers-reduced-motion` 時全部關掉。
- 還沒做（使用者說之後再調）：分頁內容切換淡入、地圖頭像出現消失、導航轉彎卡換下一個、足跡／戰情室抽屜細節、首頁卡片、拖曳跟手阻尼。

## 4. 動態島、底部橫條（safe area）

貼左右邊緣的元件都改成 `max(原本間距, env(safe-area-inset-left/right))`，底部用 `safe-area-inset-bottom`：導航轉彎卡／橫幅／抽屜／浮鈕／速度／返回目前位置、規劃頁 `.top`／`.pick`／`.psheet`、回放 `.pbar`、`.rtop`、足跡 `.fpmode`、行程頁 SOS 與跟隨膠囊、`.panel` 的 bottom、`.qx-turn`、地圖左下標示。跟側欄寬度相關的位置都要加上 `max(var(--edge),env(safe-area-inset-left,0px))`（以前漏算，回放播放列被壓在側欄底下）。

驗證方法：Playwright 開 CDP session，`Emulation.setSafeAreaInsetsOverride({insets:{left:59,right:59,bottom:21,top:0}})`，viewport 852×393。

## 5. 返回鈕（`web/assets/back.js`，common.js 會 re-export）

- `<a data-back href="備用">`：上一頁（`document.referrer`）是本站、不是 `/login`、`/w/`、也不是同一頁 → `history.back()`；否則照 href 走。
- `data-back-to="/trip"`：只有上一頁是那頁才 back（戰情室電腦版的「行程頁」鈕；足跡頁用 `data-back-to="/"`，使用者要足跡返回一律回首頁）。
- `goBackOr(url)`：做完事要回上一層時用（規劃頁「改用這條路線」、導航預覽結束），上一頁就是那裡就 back，否則 `location.replace`，不在歷史紀錄多疊一層。
- 登入成功、登出改 `location.replace`。足跡頁換分頁改 `replaceState`（以前 pushState，返回會一格一格退分頁）。
- 備用網址：戰情室、規劃 → 這趟行程頁；關於、管理 → 設定；其他 → 首頁。
- 焦點保護：頁面剛顯示或從背景切回 1.5 秒內、使用者沒碰螢幕就拿到焦點的輸入框會 blur（首頁邀請碼鍵盤自己跳出來；Chromium 重現不出來，判斷是 iOS 還原焦點，**等使用者 iPhone 確認**）。
