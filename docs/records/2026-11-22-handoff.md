## 2. 戰情室版面（`web/war.html`、`war-m.js`、`war-m.css`、`war.js`）

- `war.html` 的路由：**手機直拿**載入 `<template id="warM">` ＋ `war-m.*`；**電腦和手機橫拿**載入原本的 `war.*`（可編輯浮動面板）。
- 手機版結構：全螢幕 `#map`、漸層標題列 `.whd`、右上 `.tools`、`#sosbar`、通知 `#note`、抽屜 `section.wsheet#sheet`。
- **抽屜三段**：`peek`（進度條 `#strip`＋三個數字 `#kpi`＋分頁鈕）／`mid`（約 52% 高）／`full`（整頁）。
  - 自己寫的 pointer 拖曳（沒用共用 `sheetDrag`）。移動超過 7px 才開始拖；拉過頭有 1/3 阻力。放手時用 `off + 速度×200` 找最近的一段；甩超過 0.6 px/ms 至少跳一段。
  - 只有 `full` 時清單可以捲（`.sheet-body.scroll`）；捲到頂再往下拉就變成拉抽屜。iOS 要在 `touchmove` 呼叫 `preventDefault`。
  - 點把手會循環 peek→mid→full→peek；收起時點分頁會停在 mid。
- **地圖留白跟著抽屜**：`padRaw()` 每一格讀 `sheet.getBoundingClientRect().top`（不平滑），所以拖曳中、動畫中車隊都在看得到的那塊地圖中間。右上工具列依 `--sheet-t` 在接近全開時才滑走。
- **分頁**：
  - 騎士：照騎行順序排。第 1 名寫「領先」，其他人寫 `+分:秒` 或 `+距離`（`#gm` 切換）。時間差用全隊中位速度 `teamKmh()` 換算，所以停在同處的人是 `+0:00`。
  - 路線：直式路線圖 `#lin`，加上路況與天氣 `#wx`。
  - 事件、剖面。
- **通知** `NOTIFY`：落隊、失聯、偏離、停太久、到站、全員到齊、路況、天氣。通知會排隊；往上滑超過 24px 就收掉，點一下會選那位騎士。

## 3. 隊員身分（後端 `trips.py` 等）

- Redis 用 `trip:{tid}:role`（hash，uid → `viewer` | `car`），**沒有這筆就是騎士**。`trips.py riders_of()` 取騎士名單。
- 加入：首頁 `#roleDlg` 選身分，`POST /join {code, role}`。之後可在行程頁「隊伍」的 `#myRole` 用 `POST /{tid}/role` 改。最後一位騎士不能改成只看（回 409）。
- **只看**：不進 active、不回報位置（行程頁 GPS 鈕停用）、不顯示在地圖和名單上，戰情室標題列會顯示「N 人觀看」。
- **後援車**：照常顯示（圖示是車），但不算進落隊（`worker.check_trip_lag`）、全員到齊（`ARRIVE_LUA` 跳過，需要把 `K.role` 傳進去）、集合點總人數（`waypoints.py`）。
- 開始行程至少要有一位騎士（否則回 409）。`kick` 時會一起刪掉身分。
- **改後端要同時重建 api 和 worker**：`docker compose up -d --build api worker`（這次踩過：worker 還在跑舊程式，全員到齊不觸發）。

## 4. 觀看連結

- 建立者在行程頁的 `#watchCard` 開連結：`POST /{tid}/watch`，`DELETE` 是關閉，換新連結前會先要求確認。Redis 存 `watch:{tok}` → tid（7 天），行程 hash 裡另存 `watch` 欄位；兩邊對得上、行程還沒結束，連結才算有效。
- 網址 `/w/{tok}` 會 302 到 `/war?id={tid}&watch={tok}`。前端 `common.js WATCH` 會在每個 API 帶 header `x-qiji-watch`，WebSocket 帶 `?watch=`。
- 後端 dependency `reader(tid, request)`：成員回傳 uid，用有效連結進來的回傳 `""`。路線、集合點、SOS、聊天、沿途 POI 都改用它。匿名看的人拿不到邀請碼和 watch 欄位。
- 連結失效時：API 回 403/404，畫面顯示「觀看連結已失效」；WebSocket 在 ping 時重新檢查，失效就用 4403 關閉，15 秒內會反應。
- **已知限制**（已告訴使用者）：
  - 用連結匿名看的人不算進「N 人觀看」。
  - 如果只剩後援車還在 active，行程不會自動結束。
