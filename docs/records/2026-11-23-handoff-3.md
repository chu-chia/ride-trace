## 2. 重點（給之後改登入頁的人）

- 左側顏色都走 `.stage` 的 `--st-*` 變數（深淺兩套在 `login.html` 開頭），不要再寫死 `#07090c`。
- 手機版底部的淡出要淡進 `var(--bg)`（頁面底色），不是 `--st-bg`，不然淺色模式會有一條邊。
- 電腦版鏡頭的右側留白是用 `.side` 的實際寬度算的；改版面寬度時一起看 `login-stage.js pad()`。
- 改 `--under` 時，`login-stage.js` 手機 `bottom` 也要跟著改（120＋`--under`）。

## 3. 試過、放棄的：背景改預錄影片

- 原因：使用者發現開登入頁 GPU 100%。量到即使隊伍點不更新，3D 地形一邊載圖磚一邊淡入加上每 9 秒飛一次，每秒仍重畫 20～55 次。
- 做過：錄製模式（`?record=1`）＋逐格渲染（換掉 `performance.now`，每 1/30 秒等圖磚載齊才截圖），4 支影片（電腦／手機 × 深淺），切換深淺從同一秒接著播。即時錄（`captureStream`／CDP screencast）會錄到沒載入的黑塊、只有 15 fps，逐格渲染才乾淨。
- 結果：使用者說**畫質太差，放棄**，分支 reset 回影片之前，這些 commit 都沒進 main，也沒留檔案。之後不要再提影片。

## 4. 本機環境

- `docker compose up -d` 會連 `demo` 一起開。Mac 的 Redis 裡有使用者 iPhone 的推播訂閱，demo 在 Mac 跑可能推通知到他手機，所以 **Mac 只開 `redis api worker valhalla`**；Demo 是在 Windows 跑的。
- 測試用 `python3 -m http.server` 開 `web/` 可以看登入頁畫面（地圖圖磚是外部的），但它不支援 Range，影片類的測試會不準。

## 5. 跟使用者討論過、還沒做的

- **全站省電**（使用者問「市面上怎麼解決耗電」）：建議順序：①用 `?perf=1` 量每頁靜止時每秒重畫幾次；②靜止時重畫歸零（跟隨、隊員內插、量測這些每格迴圈改成資料驅動，GPS 一秒一次後短動畫就停）；③地圖在動時玻璃（`backdrop-filter`）改半透明實色；④最高 30 fps。GPS 高精度只在騎乘／導航中開、位置批次上傳。
- **出發前下載沿線地圖**（使用者問「能不能像遊戲先下載」）：建立行程或出發前，把路線兩側幾公里的底圖＋地形圖磚存起來（service worker／Cache Storage），解決山區沒訊號和圖磚沒載入；對 GPU 沒幫助。iPhone Safari 可能清掉太久沒用的網站資料，包成 App 後才穩。
