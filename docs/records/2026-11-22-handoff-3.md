## 2. 哪些是玻璃、哪些維持實色

判斷原則（對照 Apple HIG `materials.md`、`maps.md`）：地圖是雜的背景，用 regular 不用 clear；騎乘中要一眼看懂的用實色；警示用實色；玻璃上不疊玻璃。

- **玻璃**：所有 `.tool`（地圖工具）、`.toast`、導航模式 `.nv-fab`（SOS 除外）`.nv-cur` `.nv-recenter` `.nv-focus` `.nv-sheet`、`.wsheet` `.psheet`、戰情室 `.war-panel` `.mobile-sheet`、各頁 `.panel`（側邊面板／手機抽屜）、手機上方 `.rtop` 的返回鈕／標題、`.followPill`、`.fpmode` 按鈕、`.pbar`、`.wnote`。
- **實色**：導航轉彎卡（`.turn-main` `.turn-then`，進階可改玻璃）、橫幅、速限、SOS、結束導航、彈出／下拉選單。
- **大面板**（抽屜、戰情室面板、側邊面板）自動比小按鈕濃 12%（`--lg-big`）。
- 抽屜裡的按鈕、卡片改半透明填色（`--lg-surface*`、導航是 `--nvg-sub`），不再疊一層玻璃。

## 3. 實作重點

- **token（`app.css` 的 `:root`）**：`--lg-a`（不透明度）、`--lg-rgb`／`--lg-rgb-float`（深淺色各一組 RGB）、`--lg-tint` `--lg-float` `--lg-big`、`--lg-blur` `--lg-bri`、`--lg-bf`（共用的 backdrop-filter：blur＋saturate＋brightness）、`--lg-rim`（內高光）。所有玻璃都寫 `backdrop-filter:var(--liquid-filter,) var(--lg-bf)`。
- **導航模式有自己的深淺色**（`body[data-nvtheme]`），不跟 app 主題，所以 `nav.css` 最後一段用 `--nvg-rgb` `--nvg-sheet` 重算底色，`--lg-a` 共用。
- **`common.js`**：`glassPrefs()` 讀設定、`saveGlass()` 存、`applyGlass()` 套用（在 `<html>` 寫 `--lg-a` `--lg-blur` `--lg-bri`，加 class `no-glass` `glass-rim` `glass-turn` `glass-sheet-lp` `glass-panel`）。每頁載入 `common.js` 時就套用一次。
- **邊緣折射**（`edgeRefraction()`）：只有 Chromium 有效，Safari 不支援 backdrop-filter 吃 SVG 濾鏡。開了以後用 MutationObserver＋ResizeObserver 替每個玻璃元件依尺寸產生位移圖，寫進 `--liquid-filter`；色散是 RGB 三通道分開位移再 screen 合成。戰情室桌機面板原本的 `liquidGlass()` 會在元件上標 `data-lg-own`，不會被蓋掉。
- **關閉的優先順序**：系統「降低透明度」＞設定頁關閉玻璃（`.no-glass`，`--lg-a:1` 加去掉模糊）＞省電模式（大面板實色，除非開「省電時抽屜也用玻璃」）。系統「增加對比」時底色固定 92%、邊框加深。

## 6. 驗證做法

- Playwright（Python）登入 wei（密碼從 `data/本機帳號.md` 讀，不印出），在 `localStorage` 塞設定後開 `/trip?id=57&nav=1`、`/replay?id=55`、`/footprint`、`/war?id=57`，取 computed `backgroundColor`／`backdropFilter`，並截圖。
- 全頁掃描：列出 `position: fixed/absolute`、有底色、但 `backdropFilter` 是 none 的元件，找漏掉的。目前只剩 SOS（刻意實色）和戰情室標題列（本來就是透明漸層）。
- Mac 上量不出效能差別（都卡在 120 fps，CDP 只降 CPU 不降 GPU），效能要在 iPhone 上看。上一份交接實測過「底色 45%＋模糊 16px、4 顆按鈕」：1%low 36 → 29～34，仍順。
