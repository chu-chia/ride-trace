# 展示影片腳本（約 8 分鐘）

前半段簡報旁白（約 3 分鐘，照 `docs/簡報大綱.md`），後半段操作展示（約 5 分鐘）。OBS 錄電腦畫面；手機畫面可以用 QuickTime 鏡像或直接用瀏覽器的手機模式。

## 錄之前準備

```bash
cd ~/development/qiji && docker compose up -d
cd backend
# 終端機 A：準備好但先不要按 Enter
uv run python -m tools.simulate --group wuling --code <邀請碼> --speed 15
# 終端機 B：給「前方測速」那段用
uv run python -m tools.simulate --group beiyi --create "北宜測速" --speed 15
# 終端機 C：顯示 Redis 在做什麼（證明資料真的進 Redis）
docker exec -it qiji-redis-1 redis-cli MONITOR | grep -E "GEOADD|XADD|PUBLISH|FT.SEARCH" --line-buffered
```

## 小提醒

- 模擬器的時間戳是「重播時間」，所以 15 倍速錄的行程，回放仍是真實時長。
- 錄完記得 `pkill -f tools.simulate`，並把錄影用的行程結束掉。
- 個人足跡畫面（熱力圖、點亮鄉鎮）會露出你常去的地方，錄之前想清楚要不要放進影片。
