# 報告網頁規格（2026-11-23 與使用者確認）

## 定位

- 用途：**上台報告（15～20 分鐘）**、給老師和同學自己點開看。展示影片之後再決定怎麼錄。
- 課程是資料庫：**資料庫內容約六成**，功能展示當例子。
- 發布：**GitHub Pages，放在 ride-trace 同一個 repo**，GitHub Actions 自動發布到 `https://chu-chia.github.io/ride-trace/`。README 連過去。

## 形式

- **長捲動報告＋簡報模式**：預設左側目錄、往下捲；按一個鍵切成 16:9 一頁一頁翻（方向鍵），每一章＝一頁或數頁。
- **Demo 版面**：長捲動時「左文右 demo」，右邊裝置外框固定不動，捲到哪一章就切到對應頁面。手機外框為主，戰情室、後台用桌機外框。簡報模式在該頁裡放同一個 demo。
- **Demo 來源：兩種都要**
  - 預設：展示模式 `?demo=1`，真正的騎跡頁面＋錄好的資料（全隊移動、警示、回放都會動），不靠後端，GitHub Pages 上可用。
  - 按鈕切到正式機即時版：`https://node.tail866fc3.ts.net:8443`（Windows 關機時提示改用展示模式）。
- **展示模式的足跡資料**：用使用者真實資料，**只放格子（約 160 m）、點亮鄉鎮、每月里程，不放原始 GPS 點和時間**。
- **風格**：跟騎跡 App 一致（深色＋橘色重點色、地圖與路線為主視覺），**深色為主、可切淺色**，嵌入的 demo 一起切。
- **封面**：登入頁那張會動的台灣 3D 地形＋經典路線巡航。

## 互動元素（全部要）

1. 一筆 GPS 回報的動畫：點進來 → Pipeline 十幾個指令 → Pub/Sub → Worker，一步一步亮起來
2. Redis 指令對照：每個功能可展開「實際下的 Redis 指令」與「換成 SQL 會怎麼寫」
3. 互動 ER 圖＋key 瀏覽：點實體顯示對應的 key、型別、實際資料範例
4. 術語滑過顯示說明（Stream、TTL、Consumer Group…）

## 老師和同學怎麼操作正式機

自己註冊（現在就開放）；報告放 Demo #57（中橫）的**觀看連結**，免登入就能看車隊即時跑。

## 講稿

手機版逐頁講稿（對應每一章，含 ▶ 操作提示與時間），放一個手機能開的連結。

## 實作（2026-11-23）

| 檔案 | 內容 |
|---|---|
| `report/index.html`、`report.css`、`report.js` | 報告本體（長捲動＋簡報模式、ER 圖、GPS 回報動畫、Redis／SQL 切換、術語、QR code） |
| `report/notes.html` | 手機版講稿（約 20 分鐘，含計時器） |
| `report/app-demo/demo.js` | 展示模式：攔截 `fetch('/api/…')` 與 `WebSocket('/ws/…')`，改讀 `demo-data/`；時間戳平移到現在；播完重新整理再播 |
| `report/demo-data/*.json` | 錄好的資料（`scripts/pages/record_demo.py` 在 Mac 錄） |
| `scripts/pages/build.py` | 產生 `_site/`：報告在根目錄，`web/` 複製到 `/app/` 並改寫絕對路徑、注入 demo.js |
| `scripts/pages/serve.py` | 本機預覽 `http://localhost:8756/ride-trace/` |
| `.github/workflows/pages.yml` | 推到 main 自動發布 GitHub Pages |

- 簡報模式：`S` 切換、方向鍵／PageUp／PageDown 翻頁、`F` 全螢幕、`Esc` 離開；網址加 `?slides` 直接進簡報。焦點在嵌入的頁面裡時，這幾個鍵也會轉給報告。
- 展示資料的隱私：足跡只放格子等級（軌跡線吸附到約 160 m 格子中心），每日里程改成「每月騎幾天＋該月總里程」、日期不是真的；熱力圖放大的原始點（`/api/me/heat/detail`）、裝置 ID、推播、後台都不錄。
- 錄製：展示帳號 `demo_wei`（暱稱嘉瑋）＋機器人，30 倍速重播 3/14 中橫，成員沒有人訂閱推播。**錄製期間不要重啟 api／worker**（WebSocket 會斷，錄到的訊息不完整）。
- 正式機「即時」：行程頁、戰情室走 `/demo`（後端轉址到示範車隊的觀看連結，免登入），其他頁面要登入。
