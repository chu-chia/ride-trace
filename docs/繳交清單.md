## Redis 資料庫匯出

```bash
cd backend
# 建議：展示用的乾淨版本 —— 排除 wei 的全年足跡（含熱力圖、點亮鄉鎮、個人速度、格子快取）、
# 所有登入憑證與裝置 ID，並移除所有密碼雜湊；RediSearch 索引會重建
uv run python -m tools.export_redis --mode demo --private-user wei
# 或：原封不動的完整資料庫（含個人足跡）
uv run python -m tools.export_redis --mode full
```

輸出在 `data/export/`（不進版控），再上傳到 Google Drive。載入方式：檔案改名 `dump.rdb` 放到 Redis 8 的資料目錄後啟動。

> 注意：展示行程（武嶺、北宜、台北→武嶺）的機器人軌跡，本身就是你的真實騎乘片段（模擬器重播用）。demo 匯出不會排除這些行程；如果不想給，匯出前先把那些測試行程刪掉。
