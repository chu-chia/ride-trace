一筆 GPS 回報經過的步驟

  1. 手機送出位置 POST /api/track
  2. FastAPI 用一個 Pipeline 寫入：XADD track GEOADD geo HSET state TS.ADD SET hb EX 90 XADD stream:ingest PUBLISH live
  3. WebSocket 收到 Pub/Sub 訊息，全隊畫面同步移動
  4. Worker 用 XREADGROUP 讀到這筆，判斷落隊、抵達、前方測速
  5. 需要通知時先跑 Lua 去重，再送 Telegram
  6. 如果 90 秒沒有下一筆，心跳 key 過期，Keyspace Notification 觸發失聯警示
