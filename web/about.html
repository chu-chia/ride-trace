關於騎跡

騎跡 RideTrace

機車車隊即時定位與回放：騎車時隊友互相看得到位置、落隊、失聯與 SOS 會即時提醒，結束後可以整隊回放；平常的足跡會累積成全年足跡、點亮鄉鎮與熱力圖。

DBMS 課程 Redis 專題。位置資料只存在這台伺服器的 Redis，不會送到外部服務；地圖比對用本機的 Valhalla。

足跡怎麼算的

  • 點亮鄉鎮每個位置點用 Redis 的 GEOSHAPE 空間索引查出所在鄉鎮（FT.SEARCH … CONTAINS），存進每人一個 Set；SADD 回傳 1 代表第一次點亮。
  • 熱力圖台灣切成約 160 m 的格子，每經過一次用 Sorted Set 的 ZINCRBY 加一，ZREVRANGE 取前幾名就是最常走的路；放大到街道時改用 GEO 的 GEOSEARCH BYBOX 只取畫面內的足跡點。
  • 你在各種路的速度每段路依道路類別存進 RedisTimeSeries，規劃路線時用 TS.MRANGE … GROUPBY cat REDUCE sum 算出你在省道、山路等的實際平均速度。
  • 匯入舊紀錄以前的 GPX 可以由管理者用 tools/import_gpx 匯入，匯入後一樣會點亮。
